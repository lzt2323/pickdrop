# 拾传 Rust TUI

轻量终端客户端，直接复用 `pickdrop-core`，运行时不需要 Node、Tauri 或图形桌面。终端输入使用 crossterm；没有另建同步服务、后台守护进程或 RPC 端口。旧 Node TUI 仅从 Git 历史参考命令和发送确认流程，当前源码不包含它。

```sh
cargo build --release -p pickdrop-tui --locked
./target/release/pickdrop --data-dir /path/to/data
```

默认使用 `auto`：启动时自动选择物理网卡上的私有局域网 IPv4（10/8、172.16/12、192.168/16），排除 Docker、VPN 等虚拟接口；没有合适网卡时仅监听 127.0.0.1，不会自动开放公网网卡。其他 Linux 不需要修改源码或照抄某台机器的 IP。设置可查看全部本机 IPv4 网卡并保存 `auto` 或指定地址，重启生效；私有自动模式只在启动时选择，不是运行中的网卡热切换。

命令行 `--bind auto` 或 `--bind IPv4` 优先于持久化设置；使用它时界面会说明下次需去掉该覆盖才能采用已保存设置。`--bind 0.0.0.0` 是明确选择监听全部 IPv4 网卡，可能对公网开放。协议没有 TLS，公网或跨网段环境需自行确认暴露范围、路由及防火墙；界面在线不代表双向下载必然可达。通过 SSH 操作不会自动转发文件服务。SSH 输入路径属于服务器，数据目录和默认保存目录是不同概念。

交互模式需要 TTY（SSH 使用 `ssh -t`）。默认进入键盘工作区：左侧菜单，右侧显示当前群聊、文件、申请或设置。方向键选择和切换焦点，Enter 确认，Esc 返回；不需要记住命令。

| 按键 | 行为 |
| --- | --- |
| ↑ / ↓，PageUp / PageDown | 当前菜单或内容列表移动 / 翻页；详情页滚动 |
| → / Enter | 从菜单进入内容；在内容列表打开选中项 |
| ← / Esc | 关闭详情或返回菜单；输入框 Esc 取消 |
| Tab / Shift+Tab | 菜单与内容切换焦点，不切换群 |
| i | 在群聊中输入消息，Enter 发送 |
| / | 打开兼容命令输入；输入时 ← / → 编辑光标 |
| Home / End | 菜单首项 / 末项；输入时移动光标 |
| Ctrl+U | 清空当前输入，便于替换预填路径 |
| Ctrl+C | 退出本次同步服务；身份、消息和附件草稿保留 |

菜单包含群聊、切群/新建群、发送文件、群内文件、邀请/加入、加入申请、设备/连接、传输/草稿、设备设置、帮助和退出。菜单上下移动立即切换右侧展示，Enter 或 → 进入内容。焦点使用箭头和高亮共同标识，设置 `NO_COLOR=1` 可禁用高亮。

- 新建/加入群：在「切换 / 新建群」选择操作，Enter 后输入名称或邀请链接。选择已有群后 Enter 切换。
- 文字：群聊按 i，或选中「发送文字」后 Enter；消息列表 Enter 查看详情，文件消息 Enter 输入保存路径。
- 发送文件：在目录列表用 ↑↓ 选择，Enter 打开目录或暂存文件；也可输入路径。暂存后进入「传输 / 草稿」，选择发送，再在确认页用 → 选中确认、Enter 发送。确认默认取消。每群最多一个草稿，重启保留，失败可重试或移除；切群不改变附件目标。
- 群内文件：选择文件，Enter 后预填默认目录与文件名，可直接确认或修改完整保存路径；按需下载、校验，拒绝覆盖已有文件。
- 邀请/加入、审批：生成邀请后显示可复制链接和邀请码；申请列表自动刷新，允许和拒绝均需确认。批准等待由共享核心负责，不依赖当前面板。
- 设备/连接、设置：查看在线状态，输入同群设备地址手动连接，修改设备名称、默认保存目录和监听配置，查看网卡及存储占用。默认目录初始为启动时的工作目录，可选择已存在的目录，支持 `~`、中文及空格；设置保存在数据目录的 `tui-preferences.json`，重启后沿用。输入时 Ctrl+U 清空旧路径。此设置仅用于接收保存，不改变发送文件浏览位置，也不自动下载文件。
- 传输/草稿：查看本次传输的状态和进度、取消活动传输、重试保留的草稿。不是持久化任务队列或后台服务。

至少 72 列时左右分栏，低于 72 列时切为单栏；菜单和内容通过相同的 ←→ / Tab 切换。最低 36 列 × 12 行，低于该尺寸显示调整提示，仍可 Ctrl+C 退出。按终端单元格宽度裁剪和换行，选择项自动进入可视区；缩放不重置表单或发送草稿。中文宽度取决于终端字体与 Unicode 宽度设置。

设置还提供两个独立清理入口：

- **清理文件缓存**：确认后调用共享核心清缓存，保留身份、群组、聊天记录、草稿、原始文件和导出文件。唯一缓存副本删除后，其他设备可能无法接收；活动的本机传输需先结束。
- **清除本机群聊数据**：默认取消；确认后还需输入 `清除本机群聊`。程序退出，停止同步运行时并保留数据目录锁后，移除本机关联群组、历史、待入群申请、草稿及缓存。保留身份、设备名、默认路径、监听设置和其他应用设置。不会解散其他设备上的群，重新加入需要邀请，历史可能再次同步回来；其他设备从本机下载会中断。不会递归删除整个数据目录或外部默认保存目录。不要把用户原始文件存入应用内部 `files` 缓存目录。

兼容命令保留：`/create`、`/groups`、`/use`、`/name`、`/invite`、`/join`、`/requests`、`/approve`、`/deny`、`/devices`、`/connect`、`/file`、`/send`、`/discard`、`/save`、`/cancel`、`/history`、`/help`、`/quit`，完整参数见界面帮助。命令 `/send` 本身即明确发送确认，不再弹出菜单确认页。

不提供旧版 Node 守护进程、systemd 管理、目录批量发送、二维码、自动接收全部文件或断点续传。需要在 SSH 断开后持续运行时，可由用户在 tmux 中启动；本工具不自动创建后台服务。旧数据不自动导入，需新建身份重新加入群，旧源码继续由 Git 历史追溯。

## 脚本与验收

`--json` 提供仅通过标准输入/输出的 JSON Lines 模式，每行调用共享核心一次，返回 `{id,ok,value}` 或 `{id,ok,error}`；没有新增网络管理 API。`save_file` 是终端适配命令，参数为 `groupId`、消息 `id` 和目标 `path`，其余方法沿用核心接口。运行期间同一数据目录只允许一个进程，EOF 正常退出。

```sh
printf '%s\n' '{"id":1,"method":"bootstrap","params":{}}' | ./target/release/pickdrop --json --bind 127.0.0.1 --data-dir /tmp/pickdrop-test
cargo test -p pickdrop-tui -p pickdrop-core --locked
python3 scripts/test-rust-tui.py target/release/pickdrop --output .build/reports/rust-tui
```

验收脚本使用独立数据和生成的文件，覆盖方向键菜单和表单、默认取消、显式文件发送、中文输入、宽窄布局与模式恢复，以及两个真实节点的审批、双向消息与文件哈希、已有目标拒绝覆盖、重启身份/历史和非法输入。它不读取已有业务文件，也不自动发送到用户的真实群。

文件发送成功表示本机缓存已准备、文件消息已发布，不等于接收端已下载。其他设备需要能够主动连接发送端的监听地址；仅有消息同步或“在线”状态不能证明该方向可达。发送端须保持运行，接收端点击接收后才下载并校验；网络失败会保留具体地址和错误，不直接断言没有文件副本。
