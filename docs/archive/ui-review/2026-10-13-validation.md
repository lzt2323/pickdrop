# UI 恢复与打磨验收 · 2026-10-13

工作分支：`codex/ui-polish-reviewed`。UI 恢复以 Rust 迁移前 `6c4262e` 为外观参照；本轮美术与动效评审基线为 `859c4c5`。不改变原有白色紧凑风格。

## 评审闭环

- UI 测试工程师列出当前实现中实际可达的 36 个页面/状态，覆盖桌面 440×720、手机 390×844、窄屏 320×640、横屏 844×390，共 136 张截图。
- 独立美术 agent 按轮廓、层级、字体、状态触达和响应布局逐项打分；独立动效 agent 按频率、时空、打断、性能策略和减少动态效果逐项打分。
- 程序员分别修正共享界面与 CSS、原生动物窗口计时；主 agent 实现并测试弹层生命周期，再交回专家复评。
- 复评发现的草稿半行裁切、窄屏图片按钮换行和传输空态截图误抓，已完成第二轮修正并补充断言、重新取图，不能用零自动 finding 代替实际看图。

最终视觉均分 **7.54 → 8.29/10**，动效复审结论 **Approve**。窄屏超长草稿滚动边缘等非阻塞细节保留在复评扣分项中。评分是特定证据下的主观评估。前后评分与修复结果见 [视觉复评](2026-10-13-visual-after.md)、[动效复评](2026-10-13-motion-after.md)。

## 主要变更

- 弹层固定标题/关闭和主要操作，长内容单独滚动；危险操作使用具体动作名及红色按钮；错误贴近字段并关联辅助技术属性。
- 成员与申请分组，传输状态与文件名分离；进度刷新保留行和按钮节点，当前操作结束后合理移交焦点。
- 圆角输入区采用外框焦点样式，手机常用按钮至少 44px；多行草稿与窄屏图片操作进一步校正。
- 少量偶发指针弹层使用 160ms opacity/transform 进入效果，键盘、高频导航和程序打开即时；支持减少动态效果与立即取消。
- 原生动物和主窗保留分体、透明、贴边和尺寸恢复；每窗口独立取消过时收起计时器。
- CSS 按组件和平台归整，删除无引用选择器、旧 collapsed-tab 入口和启动时重复 DOM 搬移，版本显示读取包版本。

旧 Electron/Expo 目录仍被脚本、测试与 CI 引用，不作为“冗余”整体删除。原有未跟踪设计材料不纳入提交。

原生 macOS smoke 验证透明动物、无系统边框主窗、8px 间隔、展开/收起/隐藏、多窗、焦点/尺寸保存恢复，以及重复离开和旧计时器取消。[报告](../../../artifacts/ui-review/native/final-product-smoke.json)。文件拖入测试覆盖授权路径和事件转发链，未以此冒充 Finder 手动拖放端到端测试。

最新 macOS 应用另通过原生点击打开设置与 Escape 返回的人工交互检查；未据此宣称帧率或完整动效体感已测。

安卓在已有 `emulator-5554` 上覆盖安装并保留数据，使用实际系统键盘验证输入、弹层滚动、标题/操作区、返回和危险操作取消。最终构建下三行草稿高度 82px、scrollTop=0、发送按钮可见；超过行数上限后内部滚动。测试后原草稿与键盘设置已恢复。[验收报告](../../../artifacts/ui-review/android-after/report.json)。
