# PickDrop 桌面 UI 审查 · 2026-10-11

依据：`apps/desktop/public/index.html`、`styles.css`、`app.js`，以及旧概念图 `docs/archive/ui-concepts/2026-10-04/A-native-light.png`。旧图是设计提案，不能当作当前运行截图。应用 ui-ux-pro-max 的 Accessibility、Interaction、Forms & Feedback、Typography 优先级；已检索 `keyboard focus modal`。

## 产品现状与保留项

当前核心是「一个群一个紧凑浮窗」：标题群切换、设备在线摘要、文件与消息时间线、底部发送框。支持贴边动物入口、拖入/拖出文件、图片预览、群邀请与申请、网络和存储管理。奶白背景 + 森林绿主按钮已是当前样式最后覆盖值，适合延续。已有 native dialog、按钮标签、Escape 关闭菜单、文件键盘操作、reduced-motion，不应把这些误报成缺失。

## Paper 桌面画板建议

1. **桌面主工作台 1440×1000**：左栏品牌、群列表（设计协作、我的设备、家庭共享），底栏设备/设置；中栏群标题、在线摘要、邀请按钮；全部/文件/图片筛选；时间分组；文件卡、文本、图片缩略图；底部拖入区与发送框。主任务是传文件，避免无关运营统计。
2. **传输中心 1440×1000**：进行中、已完成、失败三类；大文件62%及取消；失败卡带明确重试；离线待接收卡；具体文件名、来源、大小。速度/预计时间需后端支持，概念中标注建议能力。
3. **设备与邀请 1440×1000**：成员列表、设备类型、在线/离线文字状态；本机标识；邀请侧板含二维码、邀请码、地址与端口、有效期、复制；独立待处理申请，允许/拒绝。
4. **设置与存储 1440×1000**：设备名称、网络自动/手动、可用网络、缓存占用、清理预览；危险操作分区；离线提示带可执行解决入口。
5. **紧凑浮窗与贴边 1000×800 展示板**：340×560 展开窗口、右侧动物收起状态、拖入高亮、未读计数。保留产品原生独特性，不把主窗口简单等比缩小。
6. **空态/首次使用 1200×800**：单一主按钮创建群，次按钮加入群；解释同一局域网；连接中、无人在线、无文件三种状态区别明确。

画板示例内容：群「设计协作」；文件「品牌视觉规范.pdf 24.8 MB」「首页交互稿.fig 18.2 MB」「发布物料.zip 128 MB」；设备「我的 MacBook」「林同学的 Windows」「iPhone」。不得把示例文案当成真实用户数据。
