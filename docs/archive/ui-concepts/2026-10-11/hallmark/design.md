# 拾传 · 桌边交接夹

本文件是此次交互原型的共用设计规范，不锁定正式客户端实现。

## 产品判断
用户需要把眼前的文件递到另一台设备上。桌面窗口应像工具：占地小，保留接收结果，随手展开。它不需要社交软件的强气泡，也不需要云盘仪表盘。文件和来源是第一层，设备关系是第二层，文字对话提供上下文。

## 结构
桌面保持单群小窗，群名承担切换入口。连续纸页列表、单侧切角表达文件；发送进度固定在发送区域。手机采用可返回的群列表和会话，单手主要操作留在底部。终端使用同样的信息顺序和操作词，不模拟图形窗口。

## 美术
铝制文件夹与索引标签的结构逻辑，不做仿旧纸张、颗粒纹理、邮票编号或复古装饰。小面积朱红只标识发起动作与活动状态。以薄线、留白、切角建立层级，避免卡片套卡片、重复图标方块和全屏彩色气泡。

## 字体
品牌中文字标采用直立宋体，短且有分量。中文界面使用 PingFang SC / Noto Sans CJK SC，选择理由是小窗中汉字的可读性与平台连续性。数字和路径用 Menlo / IBM Plex Mono。字体仅由 tokens.css 定义，不要求下载付费字体。

## 角色和标志
动物是群的识别印章，姿态与外轮廓各异，不共用同一张圆脸。App 标志从文件夹口与纸页交接构成。16–24px 场景保留轮廓，复杂细节不承担识别。

## 交互与文案
不写功能教学小字，保留状态、来源、字节、错误与必要的破坏性确认。复制后原按钮变为“已复制”，不额外庆祝。网络与文件操作均是明确标注的本地演示，不连接真实群，不上传数据。输入内容按群保存，关闭面板保留草稿。触控目标44px，键盘焦点明确，减少动态效果时关闭位移动画。

## 文件与范围
index.html 为评审入口；desktop/mobile/terminal 为独立可用演示页；brand.html 为资产预览；assets/ 为原创 SVG；tokens.css 为共用 OKLCH 令牌；qa.json 与 review.json 记录实测及主观审查。

## 验证
320 / 375 / 414 / 768 CSS像素下检查布局。分开记录已测试、设计演示及尚需真实Electron/Android/SSH验证的能力；不把浏览器原型声称为正式产品。
