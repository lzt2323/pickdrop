# PickDrop 终端界面审查与画板内容

日期：2026-10-11。基于当前 apps/tui 源码及 ui-ux-pro-max 的焦点、键盘、信息优先级、响应式和状态反馈原则；本次未运行 TUI，也未做实机 SSH 验收。设计提案不代表功能已经实现。

## 应保留的基础

- `layout.js` 使用 string-width 与 Intl.Segmenter 处理终端字符宽度和组合字素，适合中文文件名。
- `navigation-view.js:10` 分真彩、256 色和基础色，选择态同时有 `›`，不依赖颜色。
- 当前按群保存消息选择、切换区域保留焦点，方向键预览不触发下载。
- 进行中、等待副本、失败、完成对应不同操作；保存路径可查看和修改。
- 小于 40×12 明确说明终端过小。

## 设计语言

终端不强行模拟手机圆角卡片。使用字符对齐、留白、选中背景、语义符号保持品牌。背景 #080C10、正文 #E0E7EE、次级 #9AAABA、薄荷强调 #5EE1C4、焦点底 #123E3D、警告 #F0C67A；沿用现有调色板，避免无必要变更。所有状态必须带文字，符号兼容基础终端。等宽字体按字符格构图，中文按双列估算。

## 实现前验收标准

- 160×40、120×30、80×24、60×18 均不裁掉焦点和主要动作；40×12 仍能导航或提供明确尺寸提示。
- 中文、组合 emoji、超长文件名、路径、链接不破坏字格；省略内容可通过键盘查看全文。
- 基础色/256 色/真彩模式均显示可识别焦点，不能只有色差。
- 改变终端尺寸、刷新消息、切换群后保持选择及草稿。
- 使用纯方向键完成下载和多文件发送；快捷键是加速方式，不是唯一方式。
- 真实 SSH 文件来源清楚，显示所操作主机名；预览与实机验收分开报告。
