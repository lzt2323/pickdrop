# HTML 预览使用说明

当前在 `codex/tauri-migration` 分支。本目录仅是设计原型，正式客户端仍是通过三平台 CI 与真机验收的 Tauri 迁移版本；UI 实现草稿已单独保存在本地 Git 检查点。

直接打开 `index.html` 查看图册。每个界面都包含独立 HTML 和 PNG；HTML 中的导航与按钮使用本地演示，不连接真实设备。也可从仓库根运行：

```sh
python3 -m http.server 14720 --bind 127.0.0.1 --directory docs/archive/ui-concepts
```

然后打开 `http://127.0.0.1:14720/2026-10-12/tauri-minimal/`。

重新生成图册与截图：

```sh
node docs/archive/ui-concepts/2026-10-12/tauri-minimal/build-gallery.mjs
node docs/archive/ui-concepts/2026-10-12/tauri-minimal/qa.mjs
```

QA 使用仓库已有的 Playwright，不是运行原型所需的依赖。`qa-report.json` 记录逐页小屏检查，`contrast.json` 记录实际 token 对比度。

## 覆盖

- 桌面 20 屏：欢迎、紧凑会话、群组菜单、创建、加入、等待审批、邀请、成员、申请审批、群设置、文件、文件操作、图片草稿、图片预览、传输、传输历史、缓存、设置、网络、贴边标签。
- 手机 21 屏：欢迎、群组、聊天、文件、创建、加入、手动加入、等待审批、邀请、成员、审批、群设置、群主设置、传输、历史、我的、存储、文件操作单、图片预览、图片操作单、外部分享确认。
- 状态 25 屏：加载、无群、离线、加入错误、邀请过期、相机拒绝、传输失败、失去群权限、原件不可用、键盘可视区、桌面空会话、桌面离线、桌面传输失败、手动重连、清理确认、退出确认，以及空文件／传输、清理／退出／解散确认、扫码、申请横幅和桌面加入错误。

## 优化原则

保留原有桌面小窗口与手机独立导航，统一白灰表面、蓝色主操作与系统字体。桌面使用上下文菜单，手机使用底部操作单。状态反馈同时使用文字与颜色；文件保存、连接恢复和危险操作有清楚入口。

传输历史、完整图片查看与外部分享等界面是待接入的 UI 方案，不代表新增能力已经在正式客户端验收。原型不画假设备边框、系统状态栏或系统键盘，也不暗示暂停、断点续传。

旧托管群专属页面、主机原件清理和升级流程保留在 2026-10-11 的原图册。新客户端的安全数据迁移需要另行接入，不能用静态页面替代验证。
