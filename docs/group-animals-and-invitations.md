# 群动物与三端邀请界面 · 2026-10-11

Mac、Windows、Android 统一使用「创建群聊 / 加入群聊 / 邀请设备」。创建时填写群名、选择动物，完成后显示邀请信息。邀请页显示邀请码、地址、端口；复制与重新生成按钮同宽同高。桌面二维码进入次级页面，Android 扫码与邀请链接放在加入页次级入口。复制邀请信息同时包含原邀请链接，粘贴时保留群 ID 与 peer 协议标识。

`shared/animals.js` 包含十种原创矢量小信使：猫、绵羊、猴、狗、小鸡、小蜥蜴、羊驼、兔、水獭、卡皮巴拉。新群优先选择未使用的动物，群创建者可在设置中修改。peer 群动物保存在签名 genesis 或 rename 事件中；旧 genesis 按群 ID 确定动物，不修改旧签名。各端加载同一目录素材，桌面缩小入口、群列表和手机聊天标题显示一致。旧托管群的自选动物仍是托管端资料，升级到 peer 群后随签名资料同步。

邀请地址取本次邀请码实际提供者的 endpoint；Android 不再显示原创建者的保存地址。端口不能假设固定，地址与邀请码不能代替成员审批或网络可达性。

验证：283 项 Node 测试通过；TypeScript 与双平台移动 bundle 导出通过；三个真实桌面群缩小后不重叠，按钮尺寸、透明图标与三边拖放检查通过；手机网页在 320px 完成配对、审批、群隔离与草稿回归。最终 Mac 包完成创建者退出后的文字与文件验收。Windows 真机包完成三种独立缩小图标、邀请页对齐，与 Mac 双向新文字和动物身份一致性验收。Android 新包更新 `app.pickdrop.mobile.dev` 后，原群保留、真机群列表图标正常；手机后来被使用，未继续原生新建、复制或物理扫码验收。

安装包、SHA256、素材总览和验收记录位于 `artifacts/group-animals/`。Windows 新包同时复制到桌面；Windows 测试目录、计划任务和调试通道已清理，原应用进程保留。Android 临时 UI 辅助包已卸载。
