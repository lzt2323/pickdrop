# 拾传 · 成熟工具界面预览

## 范围与参考

这是独立 HTML 设计原型，使用示例数据；不调用真实设备或修改群组。沿用 `codex/tauri-migration`，正式客户端的 UI 实现等待预览反馈。

参考 2026-10-11 的 `desktop-product` 与 `mobile-product` 真实页面图册。桌面保留紧凑会话窗口、贴边标签和可选宽工作区；手机保留群组／传输／我的三项导航。不会把桌面界面直接缩成手机界面。

## 统一设计系统

- Genre：modern-minimal；App macrostructure：Workbench。
- 白色内容、浅灰辅助表面、深灰正文，蓝色仅用于主要操作与选中状态。
- 系统 UI 字体，中文回退 PingFang SC / Microsoft YaHei；字号正文 16，元数据 13，标题 18–22。
- 圆角控件 8、文件卡片 12、短操作单 16；边框代替大片阴影与玻璃效果。
- 4 / 8 / 12 / 16 / 20 / 24 / 32 间距。所有色彩、字体与间距来自 tokens.css。
- 图标为一致的 24px stroke SVG；不引入图标包、远程字体、位图装饰或动效库。
- 默认群标识为名称缩略字。品牌名称与已有应用标识保留。
- 主要按钮使用蓝色填充；次要按钮使用轻边框；危险操作独立分组。
- 各屏有明确返回／关闭路径。加载、空态、等待审批、离线、失败、取消和权限拒绝单独展示。
- 只提供当前已支持的取消与重试，不设计暂停或断点续传。

## 平台差异

桌面紧凑稿 440×720；宽工作区 960×720。鼠标菜单有可见按钮入口，窗口固定、隐藏、贴边与多窗口分别呈现。

手机主要稿 390×844。页面导航与短操作单区分；主触控目标 48px，底部 safe area、长文件名与键盘占用后可见区域分别验证。

原型不绘制假手机边框、系统状态栏、系统键盘或浏览器标题栏。键盘状态使用减少后的可视区域呈现。

## 覆盖与交付

desktop/、mobile/、states/ 每个界面一个 HTML 文件，共享平台样式及轻量脚本。index.html 提供按平台的页面目录；shots/ 存放逐页 PNG。每个新增原型页面的行为仅为演示导航与状态切换。

在 320 / 375 / 414 / 768 宽度检查溢出、按钮换行、可见焦点与触控目标；桌面另检查 440 与 960 宽。未知能力或规划能力在图册中说明，不把原型当作已实现功能。

## Skill 与预检查

使用 ui-ux-pro-max 的交互、错误恢复、无障碍与响应式指南，以及 Hallmark 的统一 token、功能优先、无装饰性 enrichment 和逐页视觉检查原则。

现有资料使用系统字体、蓝色主操作、白色内容、无重型动效。此原型保留这些基础，优化组件层级、密度、导航和状态表达。
