# 文件预览与群组/设置改造验收

日期：2026-10-13。延续320×420桌面默认尺寸、300×360最小尺寸和原生文件拖出。

## 交付行为

- 图片消息以内容为主体；列表缩略图320像素，点击加载最长边1600像素预览，适合窗口/实际预览像素切换。小图不超过原尺寸。失败保留可用缩略图并提供打开原图，高清失败不显示实际大小切换。
- 普通文件采用类型图标、两行文件名、大小/类型及轻量保存/更多操作；未接收图片明确提示先接收。
- 群组切换显示当前勾选，创建/加入为同级入口，手机扫码单独一行。
- 设置按本机和当前群组分区；设备名称独立编辑，有效且改动后才启用保存。导航右箭头、鼠标入口标题焦点与键盘控件焦点分离。
- 解码复用权限和大小限制，最多两个并行任务；删除旧文件卡重复图标/文字按钮结构，未移除仍被脚本引用的legacy客户端。
