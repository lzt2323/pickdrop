# 自动贴边与手机文字交互验收

日期：2026-10-13。

## 交付行为

- 移除桌面手动收起按钮；拖动窗口靠近工作区左、右、上、下边缘24逻辑像素范围自动识别停靠。拖动期间不重新展开或抢位置。指针离开800ms后自动收起，指针仍在窗口内阅读/操作时保持展开；自由窗口不自动收起。
- 置顶只控制窗口层级，不阻止自动收起。弹层、缩放、文件拖放和上传仍保持保护；每个窗口仅一个合并计时器，反复离开重新计算缓冲，不干扰其他群窗口。
- 收起时显示56px动物；悬停/点击恢复窗口后隐藏独立动物，去掉原56+8px布局偏移和顶部双动物。
- 恢复依据面板自身范围。连续缩放保留对应边缘和另一轴；自由缩放保留左上角。保存源显示比例，换屏先换算尺寸，再限制mini范围。
- 手机文字不创建常驻复制按钮，不绑定双击整条复制；长按使用系统文字选择、复制。空输入框通过原生菜单粘贴，没有占位短句；真实用户草稿继续恢复。
- 删除已不用的手动收起图标及事件、触屏复制按钮样式，缩略图加载/失败占位图标限制24px。

## 验证

- 前端gallery六尺寸232状态无布局/焦点/页面错误，覆盖无手动按钮、无手机copy图标、文字可选择、空输入和24px缩略图失败占位；浏览器原生Meta+V命令实际粘贴通过，桌面无障碍复制保留。
- Rust库11/11通过，含四边/自由位置几何、1/1.5/2显示比例及1→2/2→1尺寸换算；不等同真实多屏操作。
- macOS最终debug包原生20项回归通过。实际OS set_position触发Moved后，不调用手动collapse，四边均自动收起（置顶也收）；恢复无动物偏移，四边和自由连续resize锚点稳定，拖离取消、多群计时器/文件转发均通过。隔离数据目录自动退出，正常数据未清空。
- CUA实际正常应用重启载入新版本：顶部停靠面板切换访达并移开鼠标后自动变为小动物，点击恢复后单一面板、无独立顶部动物。CUA标题拖动尝试未产生可确认位移，不将此项写成真实手势通过；四边检测由上述OS Moved测试覆盖。
- Android最终APK覆盖安装；真实长按已有消息选中文字，系统Copy菜单→长按空输入系统Paste菜单→粘贴值一致，无发送。原剪贴板仅内存暂存并恢复比较，内容未记录；原草稿/2条历史/IME设置恢复。
- 两个真实Rust节点加入审批、双向文字和512KiB SHA256一致通过；动效行为回归10项通过。

证据：`artifacts/ui-review/auto-edge/manifest.json`、`auto-edge-native/native-smoke.json`、`auto-edge-android/report.json`及系统选取/粘贴截图。源码研究及独立截图复审见 `2026-10-13-auto-edge-research.md`。本轮无真实不同DPI多显示器操作或设备FPS测量。
