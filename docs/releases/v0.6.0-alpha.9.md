# v0.6.0-alpha.9

Rust TUI 增加双栏键盘工作区：菜单、聊天、群组、文件浏览与保存、邀请审批、设备和传输草稿均提供方向键与 Enter 操作。输入表单中方向键编辑光标，Esc 返回；Tab 切换面板，不再切群。保留兼容命令与 JSON Lines 接口。

72 列以上左右分栏，较窄窗口单栏切换；最低 36×12。中文按显示宽度换行，焦点自动进入可视区。菜单文件发送和审批等操作默认取消，明确选择确认后执行；草稿按群持久化，共享 Rust 核心和协议不变。

仅更新 Linux TUI 安装；Mac、Windows、手机仍保留此前已验证的安装版本。源码统一 alpha.9，Android 源码 versionCode 6008；未创建发布标签或发布。实际检查与服务器验收记录见 [STATUS.md](../STATUS.md)。
