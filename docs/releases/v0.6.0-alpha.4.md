# 0.6.0-alpha.4 · 修复 Android 扫码闪退

修复 Android release 包裁剪 ML Kit 注册类无参构造函数，导致打开扫码时主线程空指针崩溃的问题。保留所需反射入口，并在扫码 SDK 初始化异常时清理相机界面、返回错误。

新增对实际 APK 中三个注册类构造函数的校验并接入 Android CI，避免 debug 测试通过但 release 扫码崩溃。应用标识、用户数据及预览签名不变，Android versionCode 递增为 6003；与 alpha.3 桌面端协议兼容。

保留 alpha.3 的入群审批修复。本轮不发布或创建标签，验证与设备安装记录见 [STATUS.md](../STATUS.md)。
