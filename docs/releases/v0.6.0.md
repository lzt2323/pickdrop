# 拾传 v0.6.0

GitHub 直接下载发行版，提供 macOS Apple Silicon、Windows x64、Android ARM64 和 Linux x64 终端包，不包含 iOS 或 Intel Mac 包。

## 使用

将两台设备接入可信且可互通的局域网，创建群并邀请另一台设备加入，经批准后即可发送文字。文件先暂存，确认发送后发布消息；另一台设备主动接收、校验并保存。接收完成前保持文件持有设备运行。

## 安装与升级

- macOS：解压 ZIP，将“拾传.app”移到“应用程序”后打开。本地 ad-hoc 签名，未 Apple Developer ID 签名或公证，系统可能阻止直接打开。
- Windows：运行 setup.exe 完成安装。未使用可信代码签名证书，系统可能显示未知发布者提示。
- Android：打开 APK 安装，使用项目专用私钥签名，不使用公开测试密钥。
- Linux：解压 tar.gz，在解压目录运行 `./pickdrop`。这是终端应用，不需要图形桌面。

正式图形客户端标识为 `app.pickdrop`，与 `app.pickdrop.tauri.preview` 隔离，可同时安装。首次打开需要重新入群，不会自动搬移旧历史；保留预览版即可继续查看旧数据。Android 正式签名不能直接覆盖测试签名 APK，不要求卸载旧版。

## 边界

没有 TLS、端到端加密、云中继或断点续传；不保证手机锁屏及后台长期在线。仅面向可信局域网。正式版本号不表示已经通过应用商店审核、桌面可信签名或所有设备组合验收。
