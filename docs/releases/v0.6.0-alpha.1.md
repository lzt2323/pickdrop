# 0.6.0-alpha.1 · Tauri 迁移预览

桌面与手机采用同一个 Tauri 2 客户端和 Rust 核心，前端不携带 Electron、Node.js 或 React Native/Expo 运行时。Linux 终端客户端暂保留原实现。

目标：消除同步时重复验证整份历史、无变化写盘和聊天列表整体刷新；文件校验与传输在原生后台执行，图片卡片使用缩略图。

该版本是隔离预览，应用标识 `app.pickdrop.tauri.preview`，不会覆盖原来的 Electron/Expo 客户端与数据。历史协议兼容以签名事件交叉验证和真实节点传输测试为准，不能把页面预览当作手机验收。

版本回退基线：提交 `6c4262e`，本地附注标签 `migration/tauri-base-20261012`。旧版生产入口为 `pnpm start:legacy`，旧打包命令保留 `:legacy` 后缀。不直接降级或覆盖新版数据目录。

源码构建及当前验证结果见 `docs/tauri-migration.md`。正式稳定版本须完成跨平台原生构建、手机真机与旧版互通验收后另行发布；不把该预览替换为 0.5.x 发布资产。
