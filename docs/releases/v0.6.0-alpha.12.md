# v0.6.0-alpha.12

Rust TUI 默认在启动时自动选择私有局域网网卡，无合适网卡时回到本机监听。设置可查看本机 IPv4、保存自动或指定地址，重启生效；命令行 --bind 优先。自动模式不选择公网、Docker 或 VPN 接口，不包含针对某台服务器的地址。公网监听仍需明确选择并确认。

设置增加缓存占用、清理文件缓存，以及清除本机群聊数据。清缓存保留聊天；清群聊需确认并输入“清除本机群聊”，退出同步后清理群组关联、历史、待加入申请、草稿和缓存，保留身份、设备名和设置，不清理外部原始/导出文件，也不解散其他成员的群。

源码统一 alpha.12 / Android 源码 6011。验收与实际安装范围见 [STATUS.md](../STATUS.md)。
