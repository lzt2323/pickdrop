# 0.6.0-alpha.8 · 轻量 Rust TUI

新增独立 `pickdrop` 终端程序，复用 Rust 核心，支持群组、邀请和审批、文字与文件收发、在线状态、传输取消、持久化附件草稿及明确发送。无需 Node 或图形桌面。旧 Node TUI 仅从 Git 历史参考，不恢复旧源码或依赖。

核心增加显式 IPv4 绑定入口；既有桌面/手机仍沿用默认行为。TUI 默认回环监听，局域网需显式选择绑定地址；文件保存不覆盖现有文件，同一数据目录拒绝多个进程同时运行。Linux x64 构建与验收入口接入 CI 和版本检查，具体服务器测试证据见 [STATUS.md](../STATUS.md)。

版本统一 alpha.8，Android 源码构建号 6007。本轮不重装 Mac、Windows 或手机，不创建发布标签。
