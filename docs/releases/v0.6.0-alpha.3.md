# 0.6.0-alpha.3 · 修复审批后未完成入群

修复提交申请后关闭等待面板或重启申请设备，导致主设备已允许、申请设备却没有群组和连接的问题。Rust 核心持久化待确认申请，并独立于页面继续接收和验证审批结果。

重复查询批准结果改为合并事件，保留本地新消息、后续权限和当前群组选择。等待界面对拒绝、过期和撤销明确提示并停止轮询，检查失败显示具体原因。

应用标识、用户数据目录及公开预览签名不变，Android versionCode 递增为 6002。旧版已经丢失的申请需要重新提交一次；无需删除群组、移除成员或清除应用数据。审批主机若重启并丢失内存票据，也需要新邀请。

本版本为本地修复预览，不自动发布或创建标签。测试与设备检查范围见 [STATUS.md](../STATUS.md)。
