# 0.6.0-alpha.7 · Windows 动物图标拖放初始化

Windows 的动物图标改为在目标位置以可见状态创建，避开 WebView2 对动态隐藏窗口未正确注册原生拖放目标的问题；Mac 和其他平台沿用原有创建路径。继续保留 alpha.6 的文件悬停保护、路径授权与确认发送规则。

参考 [Tauri Windows 动态隐藏窗口拖放问题](https://github.com/tauri-apps/tauri/issues/14643)，采用应用侧的最小规避，不引入依赖升级或第三方补丁。版本统一为 alpha.7，Android 源码构建号 6006；本轮仅更新 Windows 安装，Mac 保持用户已验证的 alpha.6，手机保持 alpha.4。实际验证见 [STATUS.md](../STATUS.md)。
